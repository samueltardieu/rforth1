rforth1 is a Forth compiler for Microchip PIC18Fxxx microcontrollers. It requires Python 3 and
[gputils](https://gputils.sourceforge.io/) (1.5 or later).

Run the test suite with `make tests`, or `make tests-gputils` to build a local copy of gputils first.
